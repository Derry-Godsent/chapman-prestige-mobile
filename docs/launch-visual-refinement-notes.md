# Launch Visual Refinement Notes

The previous blue launch canvas comes from the onboarding gradient, not from the existing splash gradient. The onboarding screen should use the approved Chapman website palette: warm cream as the canvas, espresso for copy, emerald for actions, and restrained warm gold for progress accents.

The originally supplied CPL PNG already contains a native alpha channel outside the mark. A compact derivative preserves that transparency so the original CPL mark can sit directly in the interface without a surrounding frame. The integrated navy wordmark plate remains part of the authentic mark and is not an additional app border.

The service illustrations are portrait images. Their shared rendering currently uses `contain`, which leaves unused space inside landscape presentation frames. The shared scene should crop with `cover` inside a clipped, rounded presentation area so each illustration reaches the frame edges cleanly.
